# MetroSafar Event Catalog

Last updated: 2026-05-18

This catalog defines analytics events introduced for Phase 5 and Phase 6. Keep event names stable and additive. Do not rename events after release without a migration note.

## Common Properties

- `user_id`: backend user/client id when available.
- `client_id`: anonymous client id from `X-Client-Id`.
- `app_version`: mobile app version/build.
- `platform`: `android` or `ios`.
- `feature_flag_state`: map of relevant Phase 5/6 flags.
- `occurred_at`: ISO-8601 timestamp generated by the client.
- `synced_at`: ISO-8601 timestamp generated by the backend when received.
- `offline_queued`: boolean.

## Trip Events

| Event | Required properties | Notes |
|---|---|---|
| `trip_mode_opened` | `source` | Fired when Trip Mode screen opens. |
| `trip_started` | `trip_id`, `start_station_id`, `source` | `source` is `manual`, `geofence`, or `ticket_scan`. |
| `trip_heartbeat` | `trip_id`, `speed_kmh`, `source` | Sampled and capped to protect privacy/battery. |
| `trip_ended` | `trip_id`, `end_station_id`, `points_awarded`, `co2_saved_kg` | Server response is source of truth. |
| `trip_detection_source` | `source`, `confidence` | Fired when signal fusion changes state. |

## Intelligence Events

| Event | Required properties | Notes |
|---|---|---|
| `eta_viewed` | `station_ids`, `confidence` | Timetable confidence until official feed lands. |
| `disruption_received` | `disruption_id`, `severity`, `line_ids` | WS first, REST fallback. |
| `route_planned` | `from_station_id`, `to_station_id`, `duration_seconds`, `transfer_count` | Fired after route options render. |
| `crowd_report_submitted` | `train_id`, `coach_id`, `crowd_level` | Rate-limited backend-side. |

## Offline Cache Events

| Event | Required properties | Notes |
|---|---|---|
| `prefetch_completed` | `content_counts`, `duration_ms` | Fired after tunnel cache prefetch. |
| `outbox_replay` | `operation_count`, `success_count`, `failure_count` | Fired after reconnect replay. |
| `offline_event_logged` | `operation_type`, `outbox_count` | Fired when mutation is queued. |

## Stamp Events

| Event | Required properties | Notes |
|---|---|---|
| `stamp_claimed` | `stamp_id`, `station_id`, `rarity`, `points_awarded`, `first_claim` | Claim result must come from backend. |
| `collection_completed` | `collection_id`, `reward_type`, `reward_value` | Fired once per completed collection. |
| `trade_proposed` | `trade_id`, `offering_count`, `requesting_count` | Friend graph is future work. |
| `trade_resolved` | `trade_id`, `status` | `status` is `accepted`, `declined`, or `expired`. |

## Audio Events

| Event | Required properties | Notes |
|---|---|---|
| `episode_started` | `episode_id`, `series`, `position_seconds` | Native playback wiring is final setup work. |
| `episode_position` | `episode_id`, `position_seconds`, `completed` | Debounced every 10 seconds when live playback exists. |
| `episode_completed` | `episode_id`, `duration_seconds` | Counts toward audio streak. |

## Live Event Events

| Event | Required properties | Notes |
|---|---|---|
| `event_countdown_viewed` | `event_id`, `event_type`, `seconds_until_start` | Home countdown card. |
| `event_joined` | `event_id`, `event_type`, `status` | Join endpoint is source of truth. |
| `event_question_answered` | `event_id`, `question_id`, `correct`, `score` | One answer per user/question. |
| `event_finished` | `event_id`, `rank`, `score`, `prize_points` | Fired when final results load. |
